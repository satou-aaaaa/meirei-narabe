# 命令ならべ

ます目のロボットに命令のカードを並べて、旗のますまで動かす1日5問のゲーム。順次・くり返し・条件分岐を、押すだけで考えます。時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/meirei-narabe/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く・一発で何問動かせるか）、解いた種類が集まる「命令帳」があります。
- 問題は「どこで止まる？」「？に入るカードは？」「何回くりかえす？」「旗に着くプログラムはどれ？」「くりかえしで短く書くと？」「何枚目でぶつかる？」「何マス進む？」など。正解すると、ロボットの通った道と「なぜ」と出典が出ます。
- 問題は424問（15種類）。チケット・回数制限はありません。
- 文字の大きさは3段から選べます。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 中身の出どころ

ロボット・ます目・命令の名前は、考え方を練習するための作りものです。実際のプログラミング言語や教材とは、名前や動きがちがうことがあります。

- [文部科学省「小学校プログラミング教育の手引（第三版）」](https://www.mext.go.jp/content/20200218-mxt_jogai02-100003171_002.pdf)：命令を順序立てる・くり返させる・条件で分岐させる（p.13）、正三角形を「3回くりかえす」で書く（p.14）、動きを分けて考え・命令にし・組み合わせる（p.15）、くりかえしで簡潔に書ける（p.25）、センサーで分岐（p.32）
- [文部科学省「小学校プログラミング教育の手引」](https://www.mext.go.jp/a_menu/shotou/zyouhou/detail/1403162.htm)
- [文部科学省「プログラミング教育」](https://www.mext.go.jp/a_menu/shotou/zyouhou/detail/1375607.htm)
- [文部科学省「小学校プログラミング教育に関する研修教材」](https://www.mext.go.jp/a_menu/shotou/zyouhou/detail/1416408.htm)

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
